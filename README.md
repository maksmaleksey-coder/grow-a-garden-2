# Grow a Garden 2

A small mobile-friendly 2D gardening prototype made with Godot 4.

## Run
1. Open Godot 4.
2. Import this folder by selecting `project.godot`.
3. Run the project (F6/F5 or the Play button).

## Prototype features
- 3x3 garden plot.
- Plant seeds, water plants, wait for growth, harvest crops.
- Buy seeds with coins.
- Automatic local save using `user://garden_save.json`.

This is an offline prototype. Online multiplayer and cloud saves are not included yet.
